# Karnel Travel Guide 🌍✈️

A comprehensive, user-friendly all-in-one travel platform built using **ASP.NET Core MVC** and a **Code-First approach**. This application serves as a complete travel guide, offering seamless navigation for finding tourist destinations, restaurants, resorts, and travel packages, complete with an integrated booking management system.

---

### ✨ Key Features

* **Role-Based Access Control:** Distinct panels and permissions tailored for standard users and system administrators.
* **Template Embedding:** Integrated custom UI templates embedded separately for both the admin panel and the user panel to ensure a professional and responsive layout.
* **Admin Panel (CRUD Operations with Multiple Images):** Administrators have full control to perform **CRUD (Create, Read, Update, Delete)** operations on travel guides, restaurants, resorts, and packages—including the ability to bind, upload, update, and delete multiple pictures dynamically.
* **All-in-One Platform:** A centralized hub combining tourist destinations, local dining, accommodation options, and custom travel packages.
* **Booking Management:** Allows users to manage their travel itineraries and reservations efficiently.
* **MVC Architecture:** Built cleanly using controllers, views, and models to ensure scalable and maintainable code structure.

---

### 🛠️ Technologies Used

* **Backend Framework:** C#, ASP.NET Core MVC, Entity Framework Core (Code-First Approach)
* **Frontend Technologies:** HTML5, CSS3, JavaScript, Bootstrap (with integrated HTML templates)
* **Database Management System:** Microsoft SQL Server (SQL Server Management Studio)
* **Development Tool:** Visual Studio 2022, Git & GitHub

---

### 📂 Project Structure

* `Karnel_Travel_Guide/` - Main source directory containing:
  * **Controllers:** Handles routing, business logic, and image upload handling.
  * **Views (Razor):** User interface pages utilizing custom layouts and embedded templates for admin and users.
  * **Models:** Database entities, view models, and image binding logic.
  * **wwwroot:** Static assets, template stylesheets, scripts, and image storage directories.
